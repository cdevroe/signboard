# Signboard 1.7.6

## What's New

- Added CLI commands to archive cards and lists, preserving their restore metadata.
- Added MCP card search with text, label, and due-date filters, sorting, and paginated summaries using the same filtering rules as the CLI.
- Added MCP list renaming and CLI board settings updates.
- Added CLI board renaming and moving, plus board duplication through both CLI and MCP. Copies receive fresh card IDs and remapped internal card links.
- Added persistent card and list ordering to both interfaces, including one-time due-date ordering. Explicit orders require every current item exactly once.
- Kept completed-list workflow settings attached to their lists when list order changes, with rollback if the settings write fails.
- Added a shared [CLI/MCP operation guide](../automation.md) and end-to-end regression coverage for these workflows.
