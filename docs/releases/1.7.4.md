## What's New

- Added auto dark mode based on system settings
- Added 42 color schemes, bringing the total to 51. Thanks @MarcusHoltz #58 
- Search color schemes by name as you type.
- Press `Cmd/Ctrl + Shift + T` to open the color schemes picker.
- Planner now uses the selected board’s color scheme across Calendar, This Week, Day, and Agenda. Thanks @MarcusHoltz #59
- Fixed: Opening another board’s card in Planner views preserves the board you were viewing.
