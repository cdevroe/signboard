# Signboard 1.7.7

## Fixes

- Fixed opening Archive immediately after archiving a card: the completed archive action no longer closes the newly opened browser.

- Fixed Windows card-editor list dropdowns reverting to the first list instead of moving the card. The next/previous-list arrow and keyboard shortcuts now handle native Windows card paths too.
- Fixed creating lists with names such as `Release 1.7: QA` on Windows by removing invalid folder-name punctuation after periods.
- Fixed board and list renames that change only capitalization on Windows and other case-insensitive filesystems.
- Kept Planner filters and Clear filters reachable in smaller windows and boards with many labels.
- Fixed the starting folder for relinking missing Obsidian notes on Windows network shares and drive roots.
- Fixed a cross-platform race where a filesystem refresh could close a Table bulk-edit menu and discard draft dates or label selections. Refresh waits until the menu closes.
- Prevented an unnecessary full-board redraw when filesystem notifications race a card drop; later external edits still refresh normally.
- Added cross-platform path regressions and expanded native Windows CI to the full Electron suite plus storage, import, archive, and CLI/MCP regressions.
